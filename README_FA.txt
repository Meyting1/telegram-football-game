# Telegram Football MVP (Prototype 0.1)

این پروژه یک نمونه اولیه وب برای بازی فوتبال دیسکی دوبعدی است.

## پیش‌نیاز
- Node.js نسخه 18 یا جدیدتر
- اینترنت برای نصب وابستگی‌ها

## اجرا روی کامپیوتر
1. فایل ZIP را استخراج کنید.
2. ترمینال را در پوشه پروژه باز کنید.
3. اجرا کنید:
   npm install
   npm start
4. در مرورگر باز کنید: http://localhost:3000

## آزمایش دو نفره
- بازیکن اول وارد شود و کد اتاق را خالی بگذارد تا اتاق ساخته شود.
- کد اتاق را برای بازیکن دوم بفرستید.
- بازیکن دوم همان کد را وارد کند.
- هر دو باید به همان سرور دسترسی داشته باشند. برای آزمایش از دو دستگاه روی اینترنت، سرور باید روی یک هاست عمومی مستقر شود.

## محدودیت‌های مهم این نسخه
- این فقط نمونه اولیه برای بررسی گیم‌پلی و ارتباط آنلاین است.
- شبیه‌سازی فیزیک در مرورگر هر بازیکن انجام می‌شود و هنوز برای مسابقه رقابتی یا پول واقعی امن و قابل اتکا نیست.
- سرور فعلاً نوبت‌ها و پیام ضربه را مدیریت می‌کند، اما وضعیت کامل بازی را به‌صورت authoritative اعتبارسنجی نمی‌کند.
- مدیریت قطع اتصال، بازگشت به مسابقه، پایان رسمی مسابقه، ضدتقلب، احراز هویت Telegram Mini App و TON Connect هنوز پیاده‌سازی نشده‌اند.
- هیچ کیف پول، پرداخت یا توکن واقعی در پروژه وجود ندارد.

## مسیر توسعه بعدی
1. انتقال شبیه‌سازی فیزیک به سرور برای جلوگیری از دست‌کاری نتیجه.
2. اضافه کردن سیستم پایان مسابقه، تایمر و مدیریت قطع اتصال.
3. افزودن احراز هویت رسمی Telegram Mini App.
4. آزمایش امنیت و بررسی حقوقی قبل از هر قابلیت جایزه یا دارایی دیجیتال.
